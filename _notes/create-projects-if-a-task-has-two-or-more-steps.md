This is from [[Getting-Things-Done-David-Allen-2016]]. In order to [[Keep a list of all active projects]], you first need to define what a project is. [[David Allen]] defines it as anything with more than one step, with a clear outcome.

Its quite a narrow definition for a project and can lead to overwhelm.
